---
title: Installation
description: Install ForgetzLint in your project.
---


Install ForgetzLint using the package manager used by your project.

## npm

```bash
npm install forgetzlint
```

## pnpm

```bash
pnpm add forgetzlint
```

## Yarn

```bash
yarn add forgetzlint
```

## Bun

```bash
bun add forgetzlint
```

## Verify Installation

After installation, verify that ForgetzLint is available in your project.

Run ForgetzLint from your project root:

```bash
npx forgetzlint
```

Or with pnpm:

```bash
pnpm exec forgetzlint
```

If the installation is successful, ForgetzLint will scan your project and report any detected issues.

## Package Manager

You only need to install ForgetzLint once for a project. After installation, you can run it through your package manager or add it as a script in your `package.json`.

```json
{
  "scripts": {
    "lint": "forgetzlint"
  }
}
```

Then run:

```bash
npm run lint
```

Continue to the [Usage](./usage) guide to learn how to use ForgetzLint.
