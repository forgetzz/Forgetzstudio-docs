Welcome to ForgetzLint.

ForgetzLint is a lightweight TypeScript linter designed to help developers detect common code issues and maintain cleaner code.

ForgetzLint provides a simple CLI and a small set of practical rules, making it easy to integrate into JavaScript and TypeScript projects without complex configuration.

## Features

* Lightweight and fast
* TypeScript support
* Simple CLI
* Works without configuration
* Customizable rules
* Configurable severity levels
* Designed for modern JavaScript and TypeScript projects
