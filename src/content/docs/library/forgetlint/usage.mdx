After installing Forgetz Studio SDK, you can import the functionality you need from the package.

## Import

Import the required module from the SDK.

```typescript
import { ... } from '@forgetzstudio/sdk';
```

The available exports depend on the SDK version and the modules included in your installation.

## Basic Example

A typical integration follows this pattern:

```typescript
import { ... } from '@forgetzstudio/sdk';

const instance = ...;
```

Use the instance or imported functions according to the API provided by the module.

## TypeScript

Forgetz Studio SDK is designed to work with TypeScript.

Type definitions are included with the package, allowing editors and TypeScript tooling to provide autocomplete, type checking, and inline documentation.

```typescript
import { ... } from '@forgetzstudio/sdk';

const value: ... = ...;
```

## Modules

If your application only needs a specific module, import that module directly instead of adding unnecessary code to your application.

For example:

```typescript
import { ... } from '@forgetzstudio/sdk';
```

Refer to the documentation for the specific module to see its available methods, parameters, and return values.

## Error Handling

Always handle errors when using operations that can fail, especially when the SDK communicates with external services.

```typescript
try {
  const result = await ...;

  console.log(result);
} catch (error) {
  console.error(error);
}
```

For configuration options, continue to the [Configuration](./configuration) guide.
