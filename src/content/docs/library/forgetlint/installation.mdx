Install Forgetz Studio SDK using the package manager used by your project.

## npm

```bash
npm install @forgetzstudio/sdk
```

## pnpm

```bash
pnpm add @forgetzstudio/sdk
```

## Yarn

```bash
yarn add @forgetzstudio/sdk
```

## Bun

```bash
bun add @forgetzstudio/sdk
```

## Verify Installation

After installation, verify that the package is available in your project.

For TypeScript projects, the SDK can be imported directly from the package.

```typescript
import { ... } from '@forgetzstudio/sdk';
```

The exact imports depend on the modules provided by the version of the SDK you are using.

## Package Manager

You only need to install the SDK once for a project. After installation, you can import the required modules wherever they are needed.

Continue to the [Usage](./usage) guide to learn how to use the SDK.
