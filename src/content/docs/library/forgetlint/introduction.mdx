Welcome to Forgetz Studio SDK.

Forgetz Studio SDK is a collection of reusable tools and utilities built to help developers simplify application development.

The SDK is designed with a simple and consistent API, making it easier to integrate Forgetz Studio functionality into JavaScript and TypeScript applications.

## Features

* Simple and predictable API
* TypeScript support
* Reusable utilities and modules
* Easy installation
* Flexible configuration
* Designed for modern JavaScript applications

This documentation is organized into several sections.

### Configuration

Learn how to configure the SDK for your application's requirements.

## Requirements

Before using the SDK, make sure your development environment supports the runtime and package manager required by the version of the SDK you are using.
